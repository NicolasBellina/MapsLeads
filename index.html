Confidentialité de MapsLeads

MapsLeads est une extension Chrome conçue pour extraire des leads visibles sur Google Maps et les exporter localement. Cette page explique quelles données sont traitées, comment elles sont utilisées, et quel rôle jouent les services tiers liés au paiement.

Dernière mise à jour : 11 août 2026 Extension Chrome Stockage local

1. Résumé

MapsLeads ne collecte pas de base de données centrale, ne vend pas de données personnelles et n'envoie pas les leads extraits vers un serveur MapsLeads. Les données de prospection restent dans votre navigateur tant que vous ne les exportez pas vous-même.

2. Données traitées par l'extension

Données Google Maps Nom de l'établissement, catégorie, adresse, note, nombre d'avis, prix, services, téléphone, site web et URL Maps visibles dans la page.
Leads extraits Les résultats extraits peuvent être conservés localement dans chrome.storage.local pour l'affichage, la session d'appels et les exports.
Fichiers exportés Les CSV et XLSX sont générés localement dans le navigateur puis téléchargés sur votre appareil. Ils ne sont pas envoyés à MapsLeads.
Paiement et accès La gestion de l'essai et de l'abonnement passe par ExtensionPay et Stripe. Ces services peuvent traiter des informations liées au compte, à l'abonnement et au paiement.

3. Comment les données sont utilisées

  • afficher et filtrer les résultats extraits depuis Google Maps ;
  • préparer des exports CSV ou XLSX ;
  • gérer la session d'appels et l'état d'avancement des leads ;
  • activer l'essai gratuit, l'abonnement et la restauration d'accès ;
  • assurer le fonctionnement technique de l'extension dans votre navigateur.

4. Partage des données

MapsLeads n'exploite pas de serveur backend propriétaire pour stocker vos leads. Les seules communications externes identifiables dans l'extension concernent :

  • Google Maps : les données sont lues depuis la page affichée dans votre navigateur ;
  • ExtensionPay : pour l'essai, la connexion et la validation de l'accès ;
  • Stripe : pour le traitement du paiement lorsque vous souscrivez un abonnement.

MapsLeads ne transmet pas automatiquement votre base de leads vers un service externe.

5. Conservation

Les données extraites sont conservées localement dans le navigateur jusqu'à ce que vous les supprimiez, que vous réinitialisiez l'extension ou que vous effaciez les données du navigateur. Les fichiers exportés restent sur votre ordinateur ou dans l'emplacement où vous les avez téléchargés.

6. Vos choix

  • vous pouvez fermer l'extension sans extraire de données ;
  • vous pouvez supprimer les données locales de MapsLeads dans Chrome ;
  • vous pouvez désinstaller l'extension à tout moment ;
  • vous pouvez gérer ou annuler votre abonnement via ExtensionPay / Stripe.

7. Mineurs

MapsLeads n'est pas destiné aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données personnelles d'enfants.

8. Modifications de cette politique

Cette politique peut être mise à jour si l'extension évolue, par exemple en cas de nouvelle fonctionnalité, d'ajout d'un service tiers ou de changement du mode de stockage. La date de mise à jour sera révisée en conséquence.
