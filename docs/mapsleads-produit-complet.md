## 1. C'est quoi MapsLeads ?

MapsLeads est une extension Chrome qui extrait automatiquement les fiches d'entreprises d'une recherche Google Maps et les exporte dans un fichier Excel (.xlsx) prêt à utiliser.

En 2 minutes, un commercial peut récupérer 50 à 100 fiches d'entreprises locales avec : nom, téléphone, adresse, site web, note Google, nombre d'avis, catégorie d'activité.

Ensuite, il ouvre la **Session d'appels** : une page dédiée dans le navigateur pour appeler les entreprises une par une, noter le résultat de chaque appel, et suivre sa prospection en temps réel.

**Tout se passe dans le navigateur. Aucune donnée ne quitte l'ordinateur. Aucun compte à créer.**

## 4. Fonctionnalités actuelles

### Extraction (popup)
- Scraping automatique des résultats Google Maps au scroll
- Champs extraits : nom, catégorie, prix, téléphone, site web, adresse, note, nombre d'avis, services (à emporter / livraison), lien Maps direct
- Filtres : type d'activité (restaurant, hôtel, générique), note minimale, avis minimum, prix maximum, sans site web, tri par opportunité/note/avis
- Score d'opportunité calculé automatiquement (0-100) : popularité + réputation + absence de site web
- Export Excel (.xlsx) avec colonnes larges, en-tête en gras, filtre automatique Excel

### Session d'appels (onglet plein écran)
- Ouverture en un clic depuis le popup après extraction
- Fiche complète par lead : nom, téléphone cliquable (tel:), site web, adresse, catégorie, note, avis, score d'opportunité
- 5 statuts par lead : À appeler / Pas de réponse / Intéressé / Pas intéressé / Rappeler
- Couleur de carte par statut (gris / orange / vert / rouge / bleu)
- Note libre par lead : champ texte pour noter les informations de l'appel
- Date de rappel : champ date visible quand statut = Rappeler, badge rouge si date dépassée
- Barre de stats en temps réel : total leads, appelés (%), intéressés, taux de conversion
- Vue Kanban : colonnes par statut, glisser-déposer pour changer le statut
- Filtres par statut avec compteurs live
- Barre de distribution colorée (répartition visuelle des statuts)
- Export XLSX filtré : exporte uniquement les leads du filtre actif

### Sécurité et confidentialité
- 100% local : aucune donnée ne quitte le navigateur
- Aucun compte à créer, aucun serveur
- Permissions minimales Chrome (activeTab, scripting, storage uniquement)
- Anti-injection de formules CSV/Excel
- Conforme MV3 (pas de code distant, pas d'eval)

## 12. Questions fréquentes

**Q : Fonctionne-t-il en dehors de la France ?**
R : Oui, sur tout Google Maps. Attention, les sélecteurs sont optimisés pour Maps en anglais ou français. Les autres langues peuvent donner des résultats incomplets.

**Q : Puis-je extraire les e-mails ?**
R : Non. Google Maps n'affiche pas les e-mails. On extrait uniquement ce qui est visible sur Maps : téléphone, site web, adresse.

**Q : Le téléphone est toujours présent ?**
R : Pas toujours. Google Maps affiche le téléphone sur la fiche détail mais pas toujours dans la liste de résultats. L'enrichissement automatique via les fiches détail est prévu en v2.

**Q : Mes données sont-elles sécurisées ?**
R : Oui. Tout reste dans votre navigateur. Aucun compte, aucun serveur, aucun cloud.

**Q : Ça marche sur Firefox ou Safari ?**
R : Non. Extension Chrome uniquement pour l'instant.

**Q : Combien de leads peut-on extraire ?**
R : En gratuit : 20 lignes max. En premium : jusqu'à 120 leads par extraction (limite de sécurité pour éviter les extractions trop longues).
